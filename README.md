# nicolascl.dev

Nicolas Kleovoulou’s portfolio across operations, digital transformation, AI and automation. Built with plain HTML, CSS and JavaScript; no application dependencies or build step.

## Experience

- Purple (`#804bf2`) and grey (`#646366`) identity, with light and dark surfaces.
- The owner’s Adobe origami elephant, recoloured in the brand palette, used as the linked header mark, desktop hero illustration and browser favicon.
- Shared theme control on all six content pages. Follows the system preference until a choice is saved; existing theme preferences are retained.
- Clickable homepage work cards and a direct route to the workflow demo.
- Interactive n8n news workflow simulation: collect four fictional articles, remove one duplicate, inspect three prepared summaries, and build a sample digest.
- Run, reset, replay, and individual stage inspection. The simulation uses prepared local content and makes no external requests or claims about actual n8n execution or project results.
- Native navigation, keyboard focus indicators, restrained hover/entrance effects, reduced-motion support, and back-to-top controls.
- Without JavaScript, all workflow stages remain visible as a complete worked example.

## Local preview

```sh
python3 -m http.server 8000 --directory public
```

Open http://localhost:8000. The homepage is `index.html`; the interactive example is `n8n-ai-news-workflow.html#workflow-demo`.

## Source of truth

Edit the HTML, CSS and JavaScript files at the repository root, and brand files in `assets/`. `styles.css` and `script.js` are shared by every content page. `thelab.css` imports those base styles and adds Lab/project styles; `thelab.js` handles native fragment focus. `workflow-demo.js` is loaded only by the news project.

Firebase serves the generated copies in `public/`. After editing root sources:

```sh
python3 scripts/sync-public.py
python3 scripts/sync-public.py --check
```

The sync script also hashes local CSS and JavaScript into `?v=` URLs, including the shared CSS import used by the Lab. The check exits with an error if a source reference has a stale version, or any root website source or brand asset is missing or different in `public/`. Both Firebase workflows run it before deployment. `public/404.html` is a hosting-only page and is not generated by this script.

## Deployment

`firebase.json` selects `public/` for the `nicolascl-dev-website` Firebase project.

- `.github/workflows/firebase-hosting-pull-request.yml` requests preview deployments for pull requests from branches in this repository; fork PRs are excluded.
- `.github/workflows/firebase-hosting-merge.yml` deploys on pushes to `main`, including merged PRs.
- Both workflows use the repository secret `FIREBASE_SERVICE_ACCOUNT_NICOLASCL_DEV_WEBSITE`. No credentials belong in source control.

Check the GitHub Actions result and preview URL before merging. Local verification does not establish Firebase credential validity or successful deployment.

## Adobe typography and release consistency

All six content pages embed the published Adobe Fonts web project `dea3jlm`, created in the owner’s Adobe account. Sofia Pro Semi Bold is served at web weight 600 for main headings and project titles. Acumin Pro 400/500/600 covers body copy, interface text and emphasis. The site keeps system fallbacks and does not bundle or self-host Adobe font files. Manage the web project in Adobe Fonts; its CSS endpoint is `https://use.typekit.net/dea3jlm.css`.

Dark mode uses softer grey-lavender text: primary `#cdc8d3`, supporting `#aaa4b1` and links `#b398e8`. Purple buttons use `#f8f3ff` labels. These combinations retain at least 4.5:1 contrast against their respective surfaces.
